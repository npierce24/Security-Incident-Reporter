MINI SECURITY INCIDENT REPORTER 
===================================================

This version uses only Python's built-in standard library. No Flask, pip, or
internet connection is required to run it.

FEATURES
- Add incident reports, track severity and status
- Search and status filtering
- Dashboard summary counts
- CSV export
- JSON storage in incidents.json

SAFETY
Use fictional training data only. Do not enter real passwords, member data, or
confidential workplace information. The server listens only on your computer
(127.0.0.1), not on your network.

TROUBLESHOOTING
- If "Address already in use" appears, another program may be using port 5000.
- If "python" is not recognized, try "py app.py".
- If the browser cannot connect, check that the server is still running and the
  address is exactly http://127.0.0.1:5000.
